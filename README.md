# 🏧 ATM Banking System (Java)

A simple console-based ATM banking application developed using **Java**.  
This project simulates basic ATM operations such as account creation, login, deposit, withdrawal, and balance checking.

The system stores user account data using **Java file handling (Object Serialization)**.

---

## 🚀 Features

- Create a new bank account
- Automatically generated account number
- Login using account number and password
- Deposit money into an account
- Withdraw money with balance validation
- Check account balance
- Account lock after **3 wrong login attempts**
- Persistent data storage using **users.dat file**
